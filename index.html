How to use

  1. Draw somethingPick Draw on the left and drag on the canvas. Use the eraser, or right-click drag, to erase. Or drop in a picture and it turns into dots.
  2. Choose an animationPick one under Animations on the right (More shows the rest). Use Add layer (top right) to give another set of dots its own animation. Press Play to watch it move.
  3. Shape the lookUnder Tuning, change the speed, size and glow. Then choose a color, a gradient, or your own.
  4. Not sure? RandomizeThe dice on the left makes a whole new piece. Press Ctrl+Z if you want yours back.
  5. Save itIn the Export panel (bottom right), pick GIF, PNG, WebM, MP4 or an HTML file. Open HTML brings a saved file back for editing.

Tips Hold Shift with Draw for a straight line. Press Space to play or pause.

Guide

  1. Draw. Pick a tool on the left and paint cells on the canvas, or upload an image in the right panel.
  2. Animate. Choose an animation, then tune the sliders and colors. Use Add layer to run different animations on the same canvas: each layer has its own dots and properties.
  3. Export. Download a GIF, PNG, video or HTML file, or copy the code for an LLM.
  4. Come back later. Use Open HTML (left panel) to load an HTML file you exported before and keep editing it. Close File starts a fresh session.
