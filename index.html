About

Dot Mania turns drawings, shapes and pictures into animated dot grids.

Draw on a 16px grid, pick an animation, then export a looping GIF or a dependency-free web component you can drop into any site.

What's New

Every update, newest first.

Guide

  1. Draw. Pick a tool on the left and paint cells on the canvas, or upload an image in the right panel.
  2. Animate. Choose an animation, then tune the sliders and colors. Turn Stacking on to run up to 3 together: the first you click is the base and each next one shapes it.
  3. Export. Download a GIF, PNG, video or HTML file, or copy the code for an LLM.
  4. Come back later. Use Open HTML (bottom right) to load an HTML file you exported before and keep editing it. Close File starts a fresh session.
